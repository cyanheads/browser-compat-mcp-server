# 0.1.4 — 2026-09-22

## Added

- **`browsercompat_search_features` gains a `path_suffix` ranking tier** matching dotted and property-value notation (`Array.prototype.at`, `display: grid`) against a BCD key's trailing segments, so an exact key match no longer ranks last or is missed entirely ([#15](https://github.com/cyanheads/browser-compat-mcp-server/issues/15)).
- **`browsercompat_search_features` gains `group` and `snapshot` filters**, combinable with `namespace` and `baseline`; nested web-features groups are included ([#12](https://github.com/cyanheads/browser-compat-mcp-server/issues/12)).
- **`browsercompat_search_features` gains `offset` paging** past the `limit` cap, with `nextOffset` in the response and an `offsetNotice` when a page lands past the end ([#17](https://github.com/cyanheads/browser-compat-mcp-server/issues/17)).
- **Tag-shaped queries like `<dialog>` are no longer stripped to nothing and rejected** — `<` and `>` are now ordinary punctuation in the search tokenizer, not markup ([#18](https://github.com/cyanheads/browser-compat-mcp-server/issues/18)).

## Fixed

- **`resolve: true` now resolves a name whose feature spans several BCD keys** (e.g. "Container queries") instead of treating the tied tier as a miss — the top tier is grouped by entity rather than counted by row ([#10](https://github.com/cyanheads/browser-compat-mcp-server/issues/10)).

## Dependencies

- `@mdn/browser-compat-data` ^8.1.1 → ^8.1.2, `web-features` ^3.38.0 → ^3.39.0, `@types/node` 26.6.1 → 26.6.2. Test fixtures and figures in `docs/design.md` were re-derived against the refreshed data.

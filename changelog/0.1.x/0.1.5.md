# 0.1.5 — 2026-09-26

## Changed

- **Argument recovery** inherits mcp-ts-core 0.13.9's safe-integer-to-string repair, field-path hints, and rejected-call key-rewrite details.
- **HTTP transport** inherits MCP SDK 2.1.0 through framework 0.13.9: modern requests missing `MCP-Protocol-Version` return 400/-32020, batches over 100 messages return 400/-32600, and admitted-origin CORS preflights allow modern request headers.
- **Telemetry** adopts framework 0.13.7's OTLP base endpoint handling and 0.13.8's opt-in `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` and `LOG_TOOL_FAILURE_PAYLOADS`, documented with their endpoint and redaction constraints.
- **Framework errors** omit stack traces and cause chains since 0.13.7 and request context since 0.13.8; output-contract failures use -32603, while domain validation remains -32007.
- **Docker** installs telemetry peers within the framework's declared ranges under the existing release-age and Socket scanner guards, including OTLP log peers; removes the unused `MCP_FORCE_CONSOLE_LOGGING` setting.
- **Packaging and tooling** exclude built bundles from npm and scratch logs/design notes from MCPB, sync framework skills and maintenance scripts, and clarify tool contracts and existing session defaults in the documentation.

## Fixed

- **Clean-checkout smoke tests** check for resource and prompt definitions without requiring empty directories that Git does not preserve ([#20](https://github.com/cyanheads/browser-compat-mcp-server/issues/20)).

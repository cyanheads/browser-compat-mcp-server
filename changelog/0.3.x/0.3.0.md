# 0.3.0 — 2026-10-26

## Added

- Publish the browser-compat-guide workflow skill at skill://browser-compat-guide/SKILL.md.
- **Agent Plugins manifests** expose the server through root `plugin.json` and `mcp.json`.

## Changed

- **Guide delivery** includes plugin, npm, Docker, and MCPB installs; server instructions distinguish scalar and batch feature inputs.
- **Development tooling** syncs framework skills, validates published skills and plugin manifests, and removes build-only MCPB content while preserving executable SDK skill modules; the issue template collects environment details in one table.
- **Dependency age policy** uses a one-day minimum release age.

## Fixed

- **Uncertain removal bounds** remain unchecked before the upper bound instead of producing false support; targets at or beyond it are removed ([#32](https://github.com/cyanheads/browser-compat-mcp-server/issues/32)).
- **Search support summaries** preserve flags, prefixes, partial support, and addition bounds ([#33](https://github.com/cyanheads/browser-compat-mcp-server/issues/33)).
- **Usage labels and attribution** identify raw percentage points of global traffic and the unknown untracked remainder ([#34](https://github.com/cyanheads/browser-compat-mcp-server/issues/34)).
- **Configuration-dependent target queries** return `invalid_target_query` with self-contained-query guidance instead of loading unavailable configuration or substituting server defaults ([#35](https://github.com/cyanheads/browser-compat-mcp-server/issues/35)).
